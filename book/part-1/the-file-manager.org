Kalem has a file manager like Emacs's Dired. Ctrl+Alt+D lists the folder of
the document, the cursor on its file; the same key goes back to the
document. The toolbar's /File Manager/ and /Projects/ buttons, the two
entries at the bottom of the list of open files, the key shown at the
right of the terminal's status line (a click works too), the File and
Project menus and the palette (type =files=, =projects= or =dired=) all get
there. Opening a folder (Ctrl+O, =kalem FOLDER=, =:e FOLDER=) lists it too.
A window has one file manager, which goes from folder to folder; the list
of open files calls it /File Manager/.

It has two views. The normal view lists a folder: permissions, size,
modification time and name, folders first. The projects view
(Ctrl+Alt+Shift+D, or /Projects/ in the Project menu) lists every project,
and only the projects, as if they were all in one folder. Opening a project
lists its folder; going up from there shows the projects again. =P=
switches between the two views.

The listing is read-only text: the arrow keys, search, and with Vim keys
=j k gg G= and =/= work as in any document. A click on a name opens it.
Commands act on the marked entries, or on the one at the cursor.

| Keys                | Command                                               |
|---------------------+-------------------------------------------------------|
| Enter, click        | Open: a folder is listed, a file opens                |
| =^=, =-=, Backspace | Parent folder (from a project's folder: the projects) |
| =n=, =p=            | Next, previous line                                   |
| =P=                 | Projects view, and back                               |
| =g=                 | Read the folder again                                 |
| =(=, =.=            | Details; dot files                                    |
| =s=                 | Sort by name, time, size, extension                   |
| =F=                 | Filter by name                                        |
| =m=, =u=, =U=, =t=  | Mark, unmark, unmark all, toggle marks                |
| =d=, =x=            | Flag for deletion; move the flagged to the trash      |
| =% m=, =* /=, =* .= | Mark by regular expression, folders, extension        |
| =* t=               | Mark the entries changed since a time                 |
| =i=                 | List the folder at the cursor below this one          |
| =K=                 | Take the listed folder at the cursor out again        |
| =c=                 | New file (a name ending with =/= makes a folder)      |
| =+=                 | New folder                                            |
| =R=, F2             | Rename or move                                        |
| =C=                 | Copy                                                  |
| =D=, Delete         | Move to the trash (asks first)                        |
| =S=, =M=, =T=       | Symbolic link, permissions, touch                     |
| Ctrl+Z              | Undo the last rename, move or move to the trash       |
| =e=                 | Edit the names as text; Ctrl+S renames, Escape stops  |
| =% f=               | Find by name under the folder (=*.org=, or a part)    |
| =A=                 | Search the text of the files under the folder         |
| =W=                 | Open with the system's application                    |
| =!=                 | Shell command on the marked files (asks first)        |
| =v=, Ctrl+T         | Preview pane; thumbnails of the pictures (graphical)  |
| =w=                 | Copy the names                                        |
| =q=                 | Close the file manager                                |

/Delete for Good/, /Copy Paths/, /Reverse Order/ and /Stop File
Operations/ are in the palette. Copying and moving run in the background,
with their progress in the status bar. When a file is already at the
destination, Kalem asks: overwrite, skip, or keep both (the new one becomes
=name (2).ext=), for that file or for all that are left. Ctrl+Z takes
back the renames, moves and moves to the trash done in this session, the
last first; it refuses when a file has been put in the way.

=e= makes the names editable, as Emacs's wdired does: change them with
any editing command (a name with a folder in it, such as =old/a.txt=,
moves the file there), then Ctrl+S renames them all at
once, names that swap included, and Escape leaves them as they were.
Nothing changes when a name is empty, two files would get the same name,
a name is taken by a file that stays, or a line was added, removed or
changed outside its name; the edit stays to fix. Ctrl+Z undoes the whole
set of renames.

=% f= lists the files and folders under the folder, at any depth, whose
names match a shell pattern (=*.org=, =report-??.pdf=) or contain the text
given, each named by its path from the folder; they open, take marks and
are copied, moved or renamed as other entries are, and =^= goes back to the
folder's own entries. =A= searches the text of the files under the folder
(its project's ignore rules when it is a project) and opens a match at its
line.

=i= lists the folder at the cursor below the folder's own entries, as
Dired's =i= does, and goes to it (to it at once when it is listed
already); its entries take marks and commands as the others do. =K=,
on a listed folder's line or its entries, takes it out of the listing
again. =* t= asks since when: an age (=30m=, =2h=, =3d=, =1w=), =today=,
=yesterday=, or a date and time (=2026-09-01=, =2026-09-01 14:30=), and
marks the entries changed since then.

=!= runs a shell command on the marked files (or the one at the cursor)
in their folder, after asking: a =*= standing alone is replaced by all of
them and the command runs once; a =?= standing alone runs it once per file
with the file there; otherwise it runs once per file with the file at the
end, as in Dired. The last line of its output shows in the status bar.
/Show in System File Manager/ (the palette) shows the file selected in
Finder, Explorer or the desktop's file manager.

In the graphical editor =v= shows a pane beside the listing with the file
at the cursor: a picture, the first lines of an Org, Markdown or other text
file, or a folder's names. Ctrl+T shows the listing's pictures (the marked
ones, or all) as thumbnails there instead; a click on one goes to its line.
The same key hides the pane.

With Vim keys the file manager's keys come first, except =n=, =p=, =w= and
Backspace, which Vim keeps; =g r= reads the folder again, =g g= goes to the
first entry, =Y= copies names and =I= lists a folder below (=i= is
Vim's insert). From a document, =-= opens the file
manager (as vim-vinegar and Doom do; in the file manager it goes up), and
so do =:Ex=, =:Explore= and =:E=; =:Projects= shows the projects. =SPC o -=
opens the file manager and comes back, =SPC o P= shows the projects and
=SPC p D= the project's folder.
