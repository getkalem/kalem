Choose /Settings/ in the Kalem menu (Ctrl+, or Cmd+,) for the theme, the
keys, the language, the text size and the font. Changes apply to every
window and are saved in =settings.toml=, in the settings directory:
=$KALEM_CONFIG_DIR=, or =kalem= in =$XDG_CONFIG_HOME=, =%APPDATA%= on
Windows, or =~/.config=. A project can have its own
=.kalem/settings.toml=, which applies over yours.

| Setting                                  | Default    | What it does                                        |
|------------------------------------------+------------+-----------------------------------------------------|
| =ui.language=                            | ="auto"=   | =auto= (the system's), =en= or =tr=                 |
| =editor.theme=                           | ="system"= | =system=, =light= or =dark=                         |
| =editor.font_family=                     | =""=       | Body font; empty for the system font                |
| =editor.code_font_family=                | =""=       | Font of code and plain text                         |
| =editor.font_size=                       | =16=       | Text size                                           |
| =editor.line_width=                      | =80=       | Width of the text column in characters (0: all)     |
| =editor.center_text=                     | =false=    | The text column in the middle of the window         |
| =editor.soft_wrap=                       | =true=     | Wrap long lines                                     |
| =editor.line_numbers=                    | =true=     | Line numbers in plain text and the source view      |
| =editor.trim_trailing_whitespace=        | =false=    | Remove the blanks at the ends of lines when saving  |
| =editor.keymap_profile=                  | ="word"=   | =word= or =vim=                                     |
| =editor.vim.modes=                       | =[]=       | Kinds of documents with Vim keys; empty for all     |
| =editor.vim.leader=                      | ="space"=  | The leader of the Vim keys (=SPC p p=)              |
| =ui.open_files=                          | ="left"=   | Open files on the =left=, at the =top=, =hidden=    |
| =editor.outline_indent=                  | =true=     | Text under a heading starts at its title (terminal) |
| =projects.auto_add=                      | =true=     | Folders under version control become projects       |
| =org.todo_keywords=                      | TODO, DONE | TODO states of files without =#+TODO=; see below    |
| =org.log_done=                           | ="none"=   | What marking a task done records                    |
| =org.enforce_todo_dependencies=          | =false=    | Open subtasks keep a task from being done           |
| =org.enforce_todo_checkbox_dependencies= | =false=    | So do unchecked boxes                               |
| =org.todo_state_tags_triggers=           | =[]=       | Tags changed with the TODO state                    |
| =files.backup=                           | =false=    | Keep the previous version as =NAME.bak=             |
| =files.details=                          | =true=     | Permissions, sizes and times in the file manager    |
| =files.show_hidden=                      | =false=    | Dot files in the file manager                       |
| =files.sort=                             | ="name"=   | =name=, =time=, =size= or =extension=               |
| =files.directories_first=                | =true=     | Folders before files in the file manager            |
| =log.level=                              | ="info"=   | How much goes to the log                            |

=org.todo_keywords= is a list such as =["TODO", "NEXT", "|", "DONE"]=: the
states after the bar are done states.

* Themes

Light and dark themes follow the system unless =editor.theme= says
otherwise; the terminal editor asks the terminal for its background. To
change colors, copy =crates/kalem-core/themes/light.toml= or =dark.toml=
to =themes/= in the settings directory and edit it; colors you leave out
keep their values.
