/Settings/ in the Kalem menu (Ctrl+, or Cmd+,) sets the theme, the
keys, the language, the text size and the font. Changes apply to every
window and are saved in =settings.toml= in the settings directory:
=$KALEM_CONFIG_DIR=, or =kalem= in =$XDG_CONFIG_HOME=, =%APPDATA%= on
Windows, or =~/.config=. A project can have its own
=.kalem/settings.toml=, which applies over yours.

The terminal editor has no settings panel: /Settings/ (Ctrl+,, or
Alt+, where the terminal cannot send it) shows the path of
=settings.toml= in the status line. Edit the file there, or use the
commands that change a setting, such as /Toggle Folder Tree/ or
/Toggle Line Numbers/, which save it. Kalem reads its settings files
when it starts, so after editing one by hand, restart it; a change
made in the panel or by such a command is read at once.

* Themes

Light and dark themes follow the system unless =editor.theme= says
otherwise; the terminal editor asks the terminal for its background.
To change colors, write =themes/light.toml= or =themes/dark.toml= in
the settings directory with a =[colors]= table of the colors to
change, as =#rrggbb= or =#rrggbbaa=; the others keep their values:

#+begin_src toml
[colors]
background = "#fdf6e3"
link = "#268bd2"
#+end_src

The built-in themes, with every color's name and what it colors, are
=crates/kalem-core/themes/light.toml= and =dark.toml= in Kalem's
source.
