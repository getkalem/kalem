#+TITLE: The Kalem Book

Kalem is an editor for plain text documents that looks like a word
processor. Bold text is bold, headings are large, tables are grids,
formulas are typeset and links are links, while the file on disk stays
the standard text it was: Org, LaTeX, CSV, BibTeX or code, byte for byte
where you did not edit it. Kalem runs as a desktop application and in a
terminal, with the same commands in both, and it has command-line tools
for scripts and CI.

This book is the one reference for Kalem. It has five parts:

- *Part I, Kalem*, is the manual: installing, the two editors, writing,
  views, projects, exporting, keys, settings and the command line.
- *Part II, the standard formats*, says exactly what Kalem does with each
  format it opens, which parts it renders, edits and exports, and against
  which reference implementation (the /oracle/) that is tested.
- *Part III, the Kalem format*, will hold the specification of Kalem's
  own document format. It is being designed.
- *Part IV, extending Kalem*, covers commands, keys, completers and the
  plugin model.
- *Part V, design*, gathers the design documents, the decision records,
  performance and terminal parity.

The appendices list every command, every setting and the command line's
help; they are generated from the code each time the book is built, so
they cannot fall behind it.

The book at the =main= branch describes the =main= branch. Its source is
the =book/= folder of the repository, written in Org; =kalem book build=
turns it into this site.
