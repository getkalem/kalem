#+TITLE: The Kalem Book

Kalem is a fast, open source, text-first editor for every plain-text
format. It opens a file as what it is, Org, Markdown, LaTeX, CSV, BibTeX
or code, and shows it the way it reads: bold text is bold, headings are
large, tables are grids, formulas are typeset and links are links, while
the file on disk stays the standard text it was, byte for byte where you
did not edit it. Other formats come as plugins, written in Rust. Kalem
runs as a desktop application and in a terminal, with the same commands
in both, and it has command-line tools for scripts and CI.

This book is the one reference for Kalem. It has five parts:

- *Part I, Kalem*, is the manual: what Kalem is, installing, the two
  editors, writing, views, projects, exporting, keys, settings and the
  command line.
- *Part II, the standard formats*, says exactly what Kalem does with each
  format it opens, which parts it renders, edits and exports, and against
  which reference implementation (the /oracle/) that is tested. It is
  written, for every format and LaTeX included, precisely enough to serve
  as the reference for later implementations, Kalem's own and others'.
- *Part III, the Kalem format*, is the specification of Kalem's own
  document format, =.klm=: its syntax, structure, stylesheets, canonical
  form, grammar and conformance.
- *Part IV, extending Kalem*, covers commands, keys, completers and the
  plugin model: plugins are compiled Rust, run as WebAssembly components.
- *Part V, design*, gathers the design documents, the decision records,
  performance and terminal parity.

The appendices list every command, every setting and the command line's
help; they are generated from the code each time the book is built, so
they cannot fall behind it.

The book at the =main= branch describes the =main= branch. Its source is
the =book/= folder of the repository, written in Org; =kalem book build=
turns it into this site.
