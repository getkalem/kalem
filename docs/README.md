# Documents

- [`design_document.md`](design_document.md): RFC 0001, the design of Kalem: vision, architecture, formats, roadmap, decisions.
- [`design_doc2.md`](design_doc2.md): RFC 0002, the standard modes and the Book (its sections on Kalem's own format were withdrawn on 2026-10-04 and are kept as the design record).
- [`../rfcs/`](../rfcs/README.md): the RFC process and the index of RFCs.
- [`roadmap.md`](roadmap.md): the plan, milestones and their tasks, from [`evaluation-2026-10.md`](evaluation-2026-10.md), the evaluation of 2026-10-04.
- [`todo.md`](todo.md): the former task list, superseded by the roadmap on 2026-10-04 and kept as the record. [`history/todo_old.md`](history/todo_old.md): the list before it, with the done tasks, the decisions and the history, frozen on 2026-10-01.
- [`excel_todo.md`](excel_todo.md), [`excel_todo2.md`](excel_todo2.md): the working lists of the spreadsheet viewer (E-numbers).
- [`releasing.md`](releasing.md) and [`release-checklist.md`](release-checklist.md): how a release is built and checked.
- [`keymaps/`](keymaps): keymap files to copy, such as Emacs's Org keys.
- [`announcements/`](announcements): drafts of announcements.

Kalem started on 2026-09-27 as "Typora for Org". On 2026-09-30, RFC 0002 made it an editor for every plain-text format, each opened as itself.
